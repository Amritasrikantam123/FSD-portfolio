# FSD Portfolio Website

#Overview

This project is a personal portfolio website developed using HTML5 and CSS3 as part of the Full Stack Development (FSD) coursework. The website showcases my profile, technical skills, projects, achievements, and contact information through a clean and responsive user interface.

#Design Rationale

The design focuses on simplicity, readability, and professional presentation. A modern color palette with subtle warm tones was selected to create an elegant and approachable appearance. The layout uses clear visual sections to help users quickly navigate through different parts of the portfolio, including About, Skills, Projects, Achievements, and Contact.

The project follows a minimal design philosophy by avoiding unnecessary elements and maintaining proper spacing, typography hierarchy, and consistent styling. Cards, section divisions, and visual highlights are used to improve content organization and user experience.

#Layout Technique Justification

The website layout is implemented using CSS Flexbox and CSS Grid. Flexbox is used for arranging navigation elements, skill sections, and smaller component alignments, while CSS Grid is used for structured layouts such as project cards and content sections.

The design follows a responsive approach using relative units, media queries, and flexible containers to ensure compatibility across different screen sizes including desktops, tablets, and mobile devices.

Semantic HTML5 elements are used to improve code structure, accessibility and maintainability.

#Known Limitations

Although the website is responsive and functional, some limitations remain. The project currently uses only frontend technologies and does not include backend functionality or database integration. Contact forms are present only as a user interface and do not process submissions.

Future improvements may include adding animations, dark mode support, backend integration, and dynamic content management using modern frameworks.
